Welcome to Automated Task Reminder System

This is a modern task management application built with Spring Boot and Thymeleaf. You can easily manage your tasks with automated reminders, priority levels, and due date tracking.

Features:

  • ✨ Create and manage tasks with detailed descriptions
  • ⏰ Set reminder times for automated notifications
  • 🎯 Assign priority levels (LOW, MEDIUM, HIGH)
  • 📅 Track due dates and identify overdue tasks
  • ✅ Mark tasks as completed to track progress
  • 🔍 Filter tasks by status and priority
  • 💾 Persistent data storage with MySQL Database
  • 🎨 Modern and responsive UI design
