Welcome to Student Management System

This is a modern student management application built with Spring Boot and Thymeleaf. You can easily manage student records, including creating, reading, updating, and deleting student information.

Features:

  • ✨ Create and manage student records
  • 🔍 Search and filter students
  • 📝 Update student information
  • 🗑️ Delete outdated records
  • 💾 Persistent data storage with H2 Database
  • 🎨 Modern and responsive UI design
